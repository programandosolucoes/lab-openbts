# Laboratório Telecom & MVNO em Docker

Ambiente conteinerizado para o curso **Telecom Academy Pro**.

## 🚀 Como Iniciar

Consulte o arquivo [`COMO_SUBIR_O_LABORATORIO.md`](COMO_SUBIR_O_LABORATORIO.md) para instruções detalhadas passo a passo.

### Início Rápido:
```bash
docker compose up -d
```

### Acesso aos Serviços:
- **Open5GS WebUI (SIM Cards / Assinantes):** http://localhost:9999 (admin / 1423)
- **Yate PBX SIP:** localhost:5060
- **Asterisk Voice AS:** localhost:5080
- **UERANSIM (Simulador 5G):** Disponível para testes via CLI
